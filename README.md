# Interpretable Machine Learning for In-Hospital COVID-19 Mortality Prediction: A Multiventer Validation Study

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![R-version](https://img.shields.io/badge/R-%3E%3D%204.0-blue.svg)](https://www.r-project.org/)

This repository contains the complete analytical pipeline for predicting COVID-19 in-hospital mortality using machine learning models integrated with SHAP (SHapley Additive exPlanations) for model interpretability. The workflow is designed in accordance with the **TRIPOD** (Transparent Reporting of a multivariable prediction model for Individual Prognosis Or Diagnosis) guidelines to ensure transparency, reproducibility, and clinical relevance.

---

## Directory Structure

```
covid19-mortality-ml-prediction/
├── data/                  ← Data directory (raw data is gitignored)
│   └── processed/         ← Aggregated, non-sensitive summary output CSVs
├── scripts/               ← Numbered, execution-ordered analysis pipeline
│   ├── 00_setup.R         ← Environment and dependency setup
│   ├── 01_sample_size.R   ← Sample size calculation using pmsampsize
│   ├── 02_data_cleaning.R ← Initial data cleaning and formatting
│   ├── 03_preprocessing.R ← Imputation, scaling, and feature engineering
│   ├── 04_rf_training.R   ← Random Forest model training and tuning
│   ├── 05_xgboost_svm.R   ← XGBoost and Support Vector Machine training
│   ├── 06_logistic_regression.R ← Baseline Logistic Regression model
│   ├── 07_model_comparison.R   ← Evaluation metrics, ROC, and PR curves
│   ├── 08_shap_analysis.R      ← SHAP-based global and local interpretability
│   ├── 09_learning_curves.R    ← Sample size vs. performance diagnostics
│   ├── 10_optimism_correction.R ← Optimism correction via bootstrap validation
│   ├── 11_calibration.R        ← Probability calibration curves and Brier scores
│   └── 12_figures.R            ← Main and supplementary figure generation
├── results/               ← Tables and figures generated by the pipeline
│   ├── tables/
│   └── figures/
├── manuscript/            ← Manuscript documents and checklists
└── docs/                  ← Documentation, codebooks, and session information
```

## 🚀 Getting Started

### Prerequisites
- R (version $\ge$ 4.0 recommended)
- [RStudio](https://posit.co/download/rstudio-desktop/) (optional, but recommended)

### Environment Setup (Reproducibility)
This project uses `renv` to manage package dependencies. To restore the exact package versions used in this analysis:

1. Open the project in R/RStudio.
2. Initialize and restore the library:
   ```R
   install.packages("renv")
   renv::restore()
   ```

---

## 🛠 Running the Pipeline

To reproduce the analysis from raw data to final figures, run the scripts in `scripts/` in chronological order:

```bash
# Run the setup script to verify packages
Rscript scripts/00_setup.R

# Execute the pipeline step-by-step
Rscript scripts/01_sample_size.R
Rscript scripts/02_data_cleaning.R
Rscript scripts/03_preprocessing.R
Rscript scripts/04_rf_training.R
Rscript scripts/05_xgboost_svm.R
Rscript scripts/06_logistic_regression.R
Rscript scripts/07_model_comparison.R
Rscript scripts/08_shap_analysis.R
Rscript scripts/09_learning_curves.R
Rscript scripts/10_optimism_correction.R
Rscript scripts/11_calibration.R
Rscript scripts/12_figures.R
```

## 📊 Models Evaluated
- **Random Forest (RF)**: Ensemble bagger for capturing non-linear feature interactions.
- **Extreme Gradient Boosting (XGBoost)**: Gradient-boosted trees optimized for high performance.
- **Support Vector Machine (SVM)**: Radial Basis Function (RBF) kernel SVM.
- **Logistic Regression**: Standard baseline to compare against clinical benchmarks.

---

## 🧪 Model Interpretability (SHAP)
We employ TreeSHAP and KernelSHAP to compute Shapley values for both global feature importance and individual patient risk explanations. This ensures clinical applicability and transparency.
